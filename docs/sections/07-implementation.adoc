=== Reports on disk

`vivado/build.tcl` (batch from repo root):

[source,tcl]
----
vivado -mode batch -source vivado/add_sources.tcl
vivado -mode batch -source vivado/build.tcl
----

`build.tcl` sets `generic {USE_ETH=1}` on `sources_1`, launches
`synth_1` then `impl_1 -to_step write_bitstream -jobs 8`, and prints:

* `*.timing_summary_routed.rpt` → WNS, TNS, WHS, THS
* `*.utilization_placed.rpt` → LUT, FF, BRAM counts
* `*.power_routed.rpt` → total power

under `itch-hw.runs/impl_1/`. Update <<performance,Performance>> and
`docs/metrics.md` badges from those reports.
