=== How to refresh

.Vivado (timing and utilization)
[source,bash]
----
vivado -mode batch -source vivado/build.tcl
----

Copy from `itch-hw.runs/impl_1/` (`*_timing_summary_routed.rpt`,
`*_utilization_placed.rpt`, `*_power_routed.rpt`) into the tables above
and `docs/metrics.md` badges.

.Simulation (latency)
[source,bash]
----
cd sim/cocotb
run_tests.cmd
----

Or on Linux / GNU make:

[source,bash]
----
cd sim/cocotb && pip install -r ../requirements.txt && make
----

NOTE: Bench LED pulse widths are human-visible stretches, not cycle
counts. Only cocotb + `latency_summary.json` may update the latency
table above.
